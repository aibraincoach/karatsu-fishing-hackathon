# Planner contract

Repackaged for **karatsu-fishing-hackathon** on 2026-10-24 from naval-association-calgary.

The planner turns RT backlog items into a single plan with explicit deliverables and verification. The PM answers the plan once; then the plan runs to completion without mid-plan stops unless RT redirects.

Plans name branches, PR boundaries (code vs docs), and what “done” evidence looks like (browser check, file paths, staging URL, check names).

During the hackathon pitch window, Part A demo delivery may precede full governance docs; document fleet work merges on its own PR when the fleet ends ([CLAUDE.md](../CLAUDE.md)).
